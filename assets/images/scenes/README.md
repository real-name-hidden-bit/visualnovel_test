# Scene Images

Place one image per scene here. Recommended naming:

- `scene_01_mansion_exterior.jpg`
- `scene_02_foyer.jpg`
- ...

Suggested resolution: 1080x1350 (portrait) or 1600x900 (landscape).
Style guide: dark, vintage, grainy noir-mystery look.

If any image is AI-generated, declare it in-app as an "AI Image" (R4 rule).
